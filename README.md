# Flight Altitude Tracker

For this project, I made a small Python program that estimates a plane's altitude between a few example measurements. I used Lagrange interpolation to estimate the altitude and the bisection method to find when it reaches a chosen height.

I also changed the measurements a little to see how that affects the estimated crossing time. The program prints the results and shows a simple text graph.

The numbers are only examples for this project. They do not describe a real flight.
